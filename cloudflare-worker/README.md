# সফর গফরগাঁও - ক্লাউডফ্লেয়ার লাইভ এজ ট্র্যাকিং (Cloudflare Worker)

এই ফোল্ডারে 'সফর' অ্যাপের রিয়েল-টাইম লাইভ ট্র্যাকিং এবং ওয়েবসকেট এজ সার্ভার কোড রয়েছে। এটি বিশ্বজুড়ে ২৫০+ এজ লোকেশন (ঢাকা সহ) থেকে আল্ট্রা-লো লেটেন্সি (<৩০ মিলি-সেকেন্ড) দিয়ে লাইভ জিপিএস লোকেশন ব্রডকাস্ট করে।

---

## 🚀 ক্লাউডফ্লেয়ারে ডিপ্লয় করার সহজ নিয়ম (১০০% ফ্রি):

### পদ্ধতি ১: ক্লাউডফ্লেয়ার ড্যাশবোর্ড থেকে (ব্রাউজারে ২ মিনিটে)
1. **[dash.cloudflare.com](https://dash.cloudflare.com)** এ লগইন করুন (ফ্রি একাউন্ট)।
2. বামদিকের মেনু থেকে **Workers & Pages** এ যান।
3. **Create Application** > **Create Worker** এ ক্লিক করুন।
4. একটি নাম দিন (যেমন: `safar-gafargaon-live`) এবং **Deploy** চাপুন।
5. এরপর **Edit code** বাটনে ক্লিক করে `worker.js` ফাইলের কোডটুকু কপি করে সেখানে পেস্ট করে দিন এবং **Save and Deploy** চাপুন।
6. আপনার তৈরি হওয়া URL-টি (যেমন: `https://safar-gafargaon-live.your-name.workers.dev`) কপি করুন।
7. সফর অ্যাপে এসে **"সার্ভার সেটিংস"** বা ক্লাউডফ্লেয়ার আইকনে ক্লিক করে URL টি পেস্ট করে **"সংরক্ষণ করুন"** চাপুন। ব্যস, আপনার লাইভ এজ ইঞ্জিন সরাসরি ক্লাউডফ্লেয়ারে কানেক্ট হয়ে যাবে!

---

### পদ্ধতি ২: টার্মিনাল / Wrangler CLI দিয়ে
```bash
cd cloudflare-worker
npx wrangler login
npx wrangler deploy
```
